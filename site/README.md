# Cloudflare Pages landing site

Use the `site` folder as the Cloudflare Pages build output.

Recommended Cloudflare Pages settings:

- Framework preset: None
- Build command: leave empty
- Build output directory: `site`
- Production branch: `main`

After the first deployment, Cloudflare will assign a permanent HTTPS address ending in `.pages.dev`.

Once the final Pages URL is known, add that exact URL to Google Search Console and then add a sitemap using the same final hostname.
