Temporal facial-expression analysis.

FacialEmotionAI combines MobileNetV2 visual features, a 20-frame temporal sequence, BiLSTM + Temporal Attention, a Real/Fake screening gate, and five-class live output.

Architecture

Webcam / Video ↓ OpenCV face detection ↓ Real / Fake discriminator ↓ MobileNetV2 feature extractor ↓ 256-D feature vector × 20 frames ↓ BiLSTM + Temporal Attention ↓ 7 → 5 class fusion ↓ Confidence-aware Sad / Neutral refinement

Research scope

FacialEmotionAI estimates visible facial-expression categories. Model confidence is not psychological certainty. The project is intended for research, learning, human-computer interaction experiments, and portfolio demonstration — not clinical diagnosis, hiring decisions, lie detection, or mental-state assessment.
